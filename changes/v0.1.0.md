# v0.1.0

## Highlights

The stdio protocol grew a semantic input layer. Alongside raw `{"t":"input"}` bytes there are now `{"t":"key","key":...,"mods":N}` for named keys with a modifier bitfield, `{"t":"paste","s":...}` which is bracketed-paste aware, and `{"t":"screen"}` to request an immediate keyframe. Encoding moved to the emulator, so a client no longer has to know how to spell Cmd+Left.

Diff frames carry a `base` field naming the seqno they were computed from. A consumer applies a diff only when `base` matches the frame it holds, which turns a dropped frame into a detectable gap instead of a silently corrupt screen. Combined with the on-join keyframe request, a reconnecting viewer is correct within one coalesce window rather than waiting out `--keyframe-interval`.

Rendering gained hyperlinks and cursor visibility. OSC 8 links and implicitly detected URLs render as anchors behind an http/https/mailto allowlist, and DECTCEM now hides the cursor overlay with `display:none` instead of leaving it painted.

Four new flags: `--record PATH` tees raw pty bytes for bench corpora, `--on-stdin-eof exit|ignore` decides whether stdin EOF takes the child down, `--die-with-parent` arms `PR_SET_PDEATHSIG` on Linux, and `--version` prints the version.

**Behavior change:** `--on-stdin-eof` defaults to `exit`. A harness that piped a finite script and expected the pty to keep running needs `--on-stdin-eof ignore`.

Performance: the damage scan is clamped to the last viewport instead of walking the whole scrollback, so it costs O(rows) rather than O(scrollback). Frame pacing moved to the leading edge, and ephemeral diff payloads ride in cross.stream frame meta rather than the CAS, cutting an append from about 30us to under 1us.

Two new examples. `examples/panes` is a niri-style multiplexer: open, split, close, zoom, and follow panes at runtime, with the ptys fitted to the browser window. `examples/through` yaws one full-screen pane to show the headless wezterm behind it projecting HTML onto the page.

Also: MIT license and install instructions (eget, Homebrew, source), prebuilt binaries for macos-arm64, linux-arm64 and linux-amd64, ADR 0001 recording the terminal emulation crate decision, a full-stack bench harness in Nushell with vendored pty corpora, and a synthetic end-to-end keyboard suite.
