Keystrokes go in as JSONL. The screen comes out as HTML, scrollback included.

## Breaking

`--on-stdin-eof` now defaults to `exit`. When stdin closes, ptyZZZ kills the pty child and shuts down. If you pipe a finite script and expect the pty to stay up, pass `--on-stdin-eof ignore`.

Two rendering changes alter the HTML your client receives. Links now arrive as `<a>` elements, and a hidden cursor renders with `display:none` instead of staying painted. Check any client that assumed a row was only `<span>` runs, or that read "cursor div present" as "cursor visible".

## Semantic input

Raw `{"t":"input"}` bytes still work. Three commands join it:

- `{"t":"key","key":"ArrowLeft","mods":8}` for named keys. `key` takes a browser `KeyboardEvent.key` name: single characters, the editing and navigation cluster, F1 through F24. `mods` is a bitfield: 1 shift, 2 alt, 4 ctrl, 8 super. The emulator encodes the result against its current modes, so your client does not need to know that Cmd+Left is `CSI 1;9D`.
- `{"t":"paste","s":"..."}`, wrapped in bracketed-paste markers when the program asked for them.
- `{"t":"screen"}` to get a keyframe immediately.

## Diffs you can check

A `diff` frame now carries `base`, the seqno it was built from. Apply it only when `base` matches the frame you hold. A dropped frame becomes a gap you can detect rather than a screen that quietly goes wrong. Keyframes carry no `base`, since a subscriber can adopt one from cold.

`{"t":"screen"}` also fixes the join delay. A client can ask for a keyframe the moment its stream is live instead of waiting out `--keyframe-interval`. The bundled `serve.nu` does this on join.

## Links and cursor

OSC 8 hyperlinks and bare URLs in the output render as anchors. The scheme allowlist is http, https, and mailto. DECTCEM is honored, so a program that hides the cursor gets a hidden cursor.

## New flags

    --on-stdin-eof exit|ignore   what stdin EOF does to the child (default: exit)
    --die-with-parent            PR_SET_PDEATHSIG on Linux, no-op elsewhere
    --record PATH                tee the raw pty byte stream to a file
    --version

## Speed

The damage scan starts at the previous viewport top rather than the scrollback base, so it costs O(rows) instead of O(scrollback). Frame pacing moved to the leading edge: after an idle period the first change emits immediately, and `--coalesce` becomes a floor on the gap between frames.

Ephemeral diffs now travel in cross.stream frame meta and skip the content store, dropping a disk write that no reader benefits from. That write benched at about 30us a frame.

## Two new examples

**examples/panes** is a niri-style strip of columns you can open, split, and close while it runs. Each pane is ptyZZZ running `nu`, sized to the browser window. `f` zooms the selected pane over the whole strip.

**examples/through** is one full-screen pane with a yaw that shows what the page really is. Turned side on, a small box behind the pane is the headless wezterm, and you can watch markup fly from it into the back of the pane. Typing still reaches `nu` while it is side on.
