# v0.2.0

ptyZZZ's browser side is now a Datastar Rocket web component: `<pty-term>`.

Mouse clicks, drags and scrolling now reach terminal apps that use the mouse, such as grok.

The binary carries the component: `ptyZZZ assets <dir>` writes it out.

## <pty-term>

`static/pty-term.js` and `static/pty-term.css` hold everything a pane needs in the browser: keys, paste, IME composition, fitting the pty to its box, pinning to live output, and the mouse. The root example, the panes example and anything else drop it in:

```html
<script type=importmap>{"imports": {"datastar": "/datastar-rocket@1.0.4.js"}}</script>
<script type=module src="/datastar-rocket@1.0.4.js"></script>
<script type=module src="/static/pty-term.js"></script>
<link rel=stylesheet href="/static/pty-term.css">
<pty-term pane=local><div class=scroll><div id=grid-local></div></div></pty-term>
```

The page brings Datastar with Rocket and names it `datastar` in an import map; `pty-term.js` imports `rocket` from that name, so the page keeps one copy. [http-nu](https://github.com/cablehead/http-nu) 0.18.4's `--datastar-rocket` serves that bundle and `SCRIPT-DATASTAR-ROCKET` writes both tags.

## ptyZZZ assets

`ptyZZZ assets <dir>` writes `pty-term.js`, `pty-term.css` and the font, embedded at build time so they always match the protocol the binary speaks. Serve the directory under any path. Or load the same files from jsDelivr, pinned to this tag.

## Mouse and focus

Two new commands, building on @e-schultz's [PR 2](https://github.com/cablehead/ptyZZZ/pull/2):

- `{"t":"mouse","kind":"press","button":"left","x":12,"y":4,"mods":0}`: press, release or move at a screen cell; the wheel arrives as buttons. The emulator encodes it in whatever format the app turned on.
- `{"t":"focus","on":true}`: focus in and out, for apps that turned on `?1004h`.

The cursor element carries `data-mouse-grabbed` while an app holds the mouse. `<pty-term>` sends mouse events only then, coalesces moves, adds up the wheel into whole rows, and shows an arrow cursor; Shift always selects text.

## Examples

The root example is one terminal filling the window. Its `/sse`, and the cube's, start at the newest keyframe instead of replaying the store, send a diff only when it follows the last frame sent, and no longer store keystrokes.

## Fixes

- Apps that redraw the whole screen at once (grok, for one) no longer show a half-drawn screen: ptyZZZ waits until the app finishes the redraw before sending it.
- The cursor and rows share one 18px pitch, so the cursor sits on its row.
